# Plan: Add `npm:@kilocode/cli` to the Tool Registry

## Overview
Add the Kilo Code CLI (`@kilocode/cli`) to the mise tool registry as a new tool entry. The package is an npm-based AI coding agent CLI published by Kilo-Org.

## Background
- **Package**: `@kilocode/cli` on npm
- **Binary name**: `kilo`
- **Description**: The AI coding agent for the terminal. Generate code from natural language, automate tasks, and run terminal commands — powered by 500+ AI models.
- **Repository**: https://github.com/Kilo-Org/kilocode
- **License**: MIT
- **Latest version**: 7.2.14 (as of Apr 2026)

## Implementation Steps

### 1. Create registry file: `registry/kilo.toml`
Create a new TOML file following the existing pattern for scoped npm packages (e.g., `gemini-cli.toml`, `jules.toml`, `devcontainer-cli.toml`):

```toml
aliases = ["kilocode"]
backends = ["npm:@kilocode/cli"]
description = "Kilo Code CLI - The AI coding agent for the terminal. Generate code from natural language, automate tasks, and run terminal commands — powered by 500+ AI models."
test = { cmd = "kilo --version", expected = "{{version}}" }
```

**Rationale for fields:**
- `aliases = ["kilocode"]`: Users may reference it as `kilocode` (matching the org/package name)
- `backends`: Uses the npm backend with the scoped package name `@kilocode/cli`
- `description`: Based on the npm package description, slightly expanded for clarity
- `test`: The `kilo --version` command outputs the version string, matching the `{{version}}` pattern used by most npm tools

### 2. Commit and create PR
- Create a new branch: `feat/registry-kilocode`
- Commit with message: `registry: add kilocode`
- Create a PR against the upstream `main` branch
